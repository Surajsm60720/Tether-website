The file browser starts at `/`, which is the list of shared folders — not the Mac’s real disk root.

## Browse

- **List** (default) or **grid**
- Sort by name, date, size, or kind
- Pull to refresh discovery from the Mac list
- Folder drill-down with ancestor jump from the title

## Search

Type in the search field to find files and folders across all shares. Tap a file to preview, or a folder to open it.

## Preview and download

Tap a file to download with an inline progress ring, then open QuickLook. Large files (over 100 MB) confirm once. Use Share or Save to Files from preview.

## Upload

Folder uploads use the system picker and only succeed where **Allow uploads** is on. Paths that escape a share are rejected.

## Transfers

Active and completed sections show progress, speed, and ETA. Keep Tether in the foreground — iOS can suspend the app and stop the copy. A Live Activity may show last-known progress on the Lock Screen and Dynamic Island.
