Tether is a Mac host and an iPhone client. Pair once with a QR code, share only the folders you choose, then browse, send, preview, or open a terminal — without a cloud account.

## Start here

1. [Quick start](/docs/quick-start) — Mac + iPhone + pair on one page
2. [Pairing](/docs/pairing) — QR, approval, revoke, Local Network
3. [Files](/docs/files) — browse, search, QuickLook
4. [Security](/docs/security) — what is encrypted, what is scoped

## Away from home Wi‑Fi

1. [Other networks](/docs/remote) — Tailscale (recommended), relay, or port forward
2. [Lid-closed awake](/docs/lid-closed) — keep the Mac reachable with the lid shut
