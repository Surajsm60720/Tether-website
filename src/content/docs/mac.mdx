The Mac app is a day-to-day control center in the Dock and menu bar.

## First-glance pages

| Page | Purpose |
| --- | --- |
| Status | Sharing switch, network line, connected phones |
| Shared folders | Add / remove folders; Allow uploads per folder |
| Inbox | Files received from the iPhone |
| iPhones | Nearby phones — Look again, Pair, Connect |
| Settings | Opens the full Settings window (same as ⌘,) |

## Shares

Folders start read-only. Turn on **Allow uploads** before the phone can write there. The reserved **Inbox** share is always writable for paired phones (default `Documents/Tether Received`).

## Inbox and Shelf

- **Inbox** lists received files: Open, Reveal in Finder, Move, Delete.
- **Shelf** is a floating strip for the latest receive batch — drag out into Finder, Mail, Slack, and other apps.
- Inbox folder, Shelf auto-show, and receive sound live in **Settings → General**.

## Settings map

- **General** — Mac name, launch at login, approval, prevent sleep, Inbox folder, Shelf / sound
- **Appearance** — theme presets, text size/weight, Dock icon
- **Devices** — paired phones + Revoke
- **Other networks** — remote listening, addresses, relay, setup code
- **Activity** / **What's new**

## Pairing window

**Pair new iPhone** shows a QR and a 16-character code (`XXXX-XXXX-XXXX-XXXX`). Both expire after 120 seconds and work once. The Mac must approve before pairing finishes.
