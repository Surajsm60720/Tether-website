## Guest Wi‑Fi blocks discovery

Many guest networks isolate clients. Use a normal LAN, or join both devices to a phone hotspot.

## Do transfers work in the background?

Keep Tether in the foreground. iOS can suspend the app; a suspended app does not continue the copy. Live Activities may show last-known state — they do not keep chunk transfers running forever.

## Can I browse the whole disk?

No. Only folders you share. `/` on the phone is the share list.

## Is there a general shell?

No. Everyday commands are virtual inside shares. Only allowlisted agent names get a live PTY.

## Windows or Android?

Out of scope for now. Mac + iPhone only.

## How do I reach home from cellular?

Pair on Wi‑Fi first, then set up Tailscale (recommended), a reachable address, or a relay. Save a fresh setup code that shows a `100.x` address (or a relay) — not only `192.168…`. See [Other networks](/docs/remote).

## What if I close the MacBook lid?

Idle-sleep prevention alone is not enough for a closed lid. Install [lid-closed awake](/docs/lid-closed) once on the Mac, turn on **Prevent sleep while active**, confirm **Holding awake**, then close the lid. Prefer AC power for long sessions.

## Do I need a relay if I use Tailscale?

No. Leave the relay field empty for the Tailscale-only path.

## Is the setup code a password for my files?

No. It carries routing info. Files and terminal still need the paired device key. Treat the code as private.
