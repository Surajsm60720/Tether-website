## 3.4

Control-tap a localhost link from a live agent to open that Mac dev server in an in-app browser tab (HMR and WebSockets tunnel through Tether).

- Control-tap a localhost link from a live agent to open that Mac dev server in an in-app browser tab (HMR and WebSockets tunnel through Tether).
- Local-dev preview keeps a warm pool of Mac tunnels so page assets and HMR load without waiting on a fresh open for every connection.
- Tap a file in Files to download it to the Files app — no Preview prompt; Search and terminal open / preview / get do the same.
- OpenCode joins the live-agent allowlist with its own Island mark; the Mac Host runs unsandboxed so agent runtimes are not Gatekeeper-quarantined.
- Removed the iOS Simulator mirror command; screen-share primitives stay in TetherCore for a later release.

## 3.3

Lid-closed awake and quieter Tailscale remote.

- **Lid-closed awake** — one-time Mac setup so Tether can keep the Mac awake with the lid shut while you need it online, then restore normal sleep
- **Hold awake on battery** — choose whether lid-closed hold works unplugged or only on AC
- Tailscale-first **Other networks** setup with clearer `100.x` addresses in the phone’s saved route
- Soft reconnects over cellular / Tailscale blips — brief stalls should not wipe a live session or agent
- Battery-aware keepalives when holding awake unplugged

See [Lid-closed awake](/docs/lid-closed) and [Other networks](/docs/remote).
