## Signing

The iPhone target must be signed with your Apple ID. A paid developer account is not required for a personal install. Bundle id defaults to `app.tether.client`.

Trust the developer certificate in **Settings → General → VPN & Device Management** if iOS asks.

## Tabs after connect

| Tab | Purpose |
| --- | --- |
| Files | Browse shares, search, preview, download / upload |
| Send | Photos / Files into the Mac Inbox |
| Terminal | Virtual shell, agents, monitor / fetch slots |
| Transfers | Active and completed transfers |

## Settings

Device name, Appearance presets (Gold / Blue / Green / Neutral / Midnight), home-screen icon, cache clear, terminal font size (11–20 pt), prevent Mac sleep while active, **Other networks** for a remote setup code, and **What's new**.

## Everyday reconnect

Tap a paired Mac. **Available** means it is on this Wi‑Fi. **Saved for other networks** means a remote code is saved and the Mac is not on this LAN.
